# taskhous

KTA25 school project for learning agile software development.

TaskHouse is a web application for a self-employed builder who currently manages project quotes, working hours and material costs in Excel. The app helps plan work and budgets for construction sites and keep track of completed work, workers' hours and expenses, so it's easy to see whether a project stays within budget.

The project is managed using Kanban. Plan: [MVP.md](MVP.md)
